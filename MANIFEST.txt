[TOP-LEVEL DIRECTORY STRUCTURE & ARTIFACT PACKAGING]

1. code/
   Core scripts, compilation pipelines, and statistical evaluation utilities:
   - step0_verify_e0_windows.py: Compiles & executes all 80 C variants across 160 assertions.
   - step1_wsl_build_and_extract.sh: Cross-compilation and context extraction runner.
   - step2_ghidra_headless_postscript.py: Ghidra Headless decompiler extraction post-script.
   - step3_mcp_server_and_benchmark.py: LLM benchmark runner (`--mode return` and `--mode mcq`, `--max-pairs 40`).
   - step4_compute_statistics_and_tables.py: Computes SCHR, 95% Wilson CI, Miss Rate, Spearman rho, McNemar, M1-M5 matrix, and N=50 CT1 error taxonomy.
   - extract_contexts.py: Leak-free normalized context generator (CT1-CT4, Obf0-Obf3).
   - eval_engine.py: Auxiliary evaluation utility.
   - live_demo.py / live_demo.sh: Interactive terminal demonstration script for Milestone D3.

2. dataset/
   Ground-truth C source pairs, compiled stripped PE64 binaries, real objdump disassembly, and MCQ suite:
   - SCHR_Bench_C_Functions/src/: 40 original + 40 mutant C source files (80 variants).
   - SCHR_Bench_C_Functions/bin/pe_x64_O2/: 80 compiled & stripped 64-bit Windows PE executables (`.exe`).
   - SCHR_Bench_C_Functions/disassembly_objdump_80.json: Real `objdump -d -M intel` disassembly for all 80 PE64 binaries.
   - SCHR_Bench_C_Functions/ground_truth_manifest.json: 40 function pair specs, mutation operators, and 80 input vectors (160 assertions).
   - SCHR_Bench_C_Functions/tools/check_suite.py & build_pe.py & runner.c: Standalone build and execution verification harness.
   - gold_set_mcq.json: 240 full-factorial paired, balanced, leak-free, length-neutral multiple-choice items (N=80 across CT1, CT2, CT3; 60 A, 60 B, 60 C, 60 D; 25.0% length-cue baseline).

3. documentation/
   Project planning and milestone notes:
   - SCHR_BENCH_MASTER_PLAN_OBSIDIAN.md: Project master plan and RBL notes.

4. manuscript/
   Academic research papers, LaTeX templates, figures, and bibliography:
   - 01_IEEE_Conference_Format_8_10_Pages/: IEEE conference manuscript (`main.tex`, `main_anonymous.tex`, `IEEEtran.cls`, and `IEEEtran.bst`).
   - 02_Springer_LNICST_Format_10_14_Pages/: Springer LNICST manuscript (`main.tex`, `main_anonymous.tex`, `llncs.cls`, and `splncs04.bst`).
   - IEEE_SCHR_Bench_Paper_8_10_Pages.zip: Packaged IEEE Overleaf archive.
   - Springer_SCHR_Bench_Paper_10_14_Pages.zip: Packaged Springer Overleaf archive.

5. prompts/
   System prompt templates:
   - mcq_system_prompt.txt: System prompt for `--mode mcq` evaluation.
   - explanation_system_prompt.txt: System prompt for structured explanation analysis.

6. results/
   Experimental outputs, statistical tables, and raw benchmark logs:
   - benchmark_raw_logs.json: Complete return-value & explanation raw logs (540 entries: 480 core CT1-CT3 runs + 60 E4 pilot runs).
   - benchmark_mcq_logs.json: Complete Full-Factorial Gold Set MCQ raw logs (480 entries: 2 models x 240 items [N=80 per tier] with real `objdump` assembly in CT2/CT3).
   - decompiled_contexts_80.json: Leak-free normalized contexts (including real PE64 `objdump -d -M intel` disassembly) for all 80 variants.
   - PAPER_TABLES_SPRINGER.md: Auto-generated statistical tables (Sections 1-7) from `step4_compute_statistics_and_tables.py`.
   - E0_sanity_check_report.txt & E0_Table1_Springer.md: Dynamic binary execution verification report (160 assertions).

7. Root Operational Files:
   - CITATION.cff: Citation File Format metadata.
   - LICENSE: MIT Open-Source License (Code) & CC BY 4.0 (Dataset).
