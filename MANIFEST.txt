[TOP-LEVEL DIRECTORY STRUCTURE & ARTIFACT PACKAGING]

1. .github/workflows/
   Continuous Integration (CI) verification pipeline:
   - ci-verify-e0.yml: Automated Ubuntu & Windows x64 workflow verifying context
     extraction, 1,020-run statistical reproduction, SSOT LaTeX macros, 20-pair
     Q4/FP16 ablation baseline, and dynamic execution of all 80 PE64 binaries.

2. code/
   Core scripts, compilation pipelines, and statistical evaluation utilities:
   - step0_verify_e0_windows.py: Compiles & executes all 80 C variants across 160 assertions.
   - step1_wsl_build_and_extract.sh: Cross-compilation and context extraction runner.
   - step2_ghidra_headless_postscript.py: Ghidra Headless decompiler extraction post-script.
   - step3_mcp_server_and_benchmark.py: LLM benchmark runner (`--mode return` and `--mode mcq`, `--max-pairs 40`).
   - step4_compute_statistics_and_tables.py: Computes SCHR, 95% Wilson CI, Pair-Level Accuracy, Canonical Parroting, Spearman rho, McNemar, Bootstrap AUROC, M1-M5 matrix, and N=50 CT1 error taxonomy.
   - step5_fp16_api_subset_ablation.py: Stratified 20-pair (N=40) Q4 vs. FP16/Cloud API control protocol runner.
   - generate_paper_macros.py: Single Source of Truth (SSOT) LaTeX macro generator (`paper_macros.tex`).
   - extract_contexts.py: Leak-free normalized context generator (CT1-CT4, Obf0-Obf3).
   - evaluate_gh0strat_case_study.py: Ecological packed malware static triage verifier.
   - plot_figure3_empirical_schr.py: Publication-grade matplotlib visualizer for Figure 3.
   - eval_engine.py: Auxiliary evaluation utility.
   - live_demo.py / live_demo.sh: Interactive terminal demonstration script for Milestone D3.

3. dataset/
   Ground-truth C source pairs, compiled stripped PE64 binaries, real objdump disassembly, and MCQ suite:
   - SCHR_Bench_C_Functions/src/: 40 original + 40 mutant C source files (80 variants).
   - SCHR_Bench_C_Functions/bin/pe_x64_O2/: 80 compiled & stripped 64-bit Windows PE executables (`.exe`).
   - SCHR_Bench_C_Functions/disassembly_objdump_80.json: Real `objdump -d -M intel` disassembly for all 80 PE64 binaries.
   - SCHR_Bench_C_Functions/ground_truth_manifest.json: 40 function pair specs, mutation operators, and 80 input vectors (160 assertions).
   - SCHR_Bench_C_Functions/tools/check_suite.py & build_pe.py & runner.c: Standalone build and execution verification harness.
   - gold_set_mcq.json: 240 full-factorial paired, balanced, leak-free, length-neutral multiple-choice items (N=80 across CT1, CT2, CT3; 60 A, 60 B, 60 C, 60 D; 25.0% length-cue baseline).
